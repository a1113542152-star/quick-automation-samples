# Quick Automation Samples

Small, same-day automation examples for public data, CSV cleanup, and lightweight reporting.

## What I can deliver

- Clean and deduplicate CSV or Excel exports.
- Convert messy product, lead, or order data into a normalized CSV.
- Build small scripts that call public APIs or public web pages.
- Create repeatable reports with clear input and output files.

## Boundaries

I only work with legal, permission-safe data. I do not bypass logins, CAPTCHAs, paywalls, rate limits, or private systems.

## Example files

- `csv_cleaner.py`: normalizes headers, trims cells, removes duplicate rows, and writes a clean CSV.
- `public_api_report.py`: fetches public JSON data and exports a simple CSV report.

Typical small tasks can be delivered in 2-6 hours when the scope is clear.
